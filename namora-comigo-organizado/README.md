# Namora Comigo? ❤️

Projeto pessoal romântico, organizado para publicação no GitHub Pages.

## Estrutura
- `index.html`: página principal.
- `minhacasa.html`: página acessada pela opção Minha Casa.
- `assets/css/`: folhas de estilo.
- `assets/js/`: JavaScript.
- `assets/img/`: imagens.
- `assets/videos/`: vídeos.

## Publicação no GitHub Pages
1. Envie o conteúdo desta pasta para a raiz do repositório.
2. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/(root)`.
3. Salve e aguarde a publicação.

O arquivo `index.html` já está na raiz e os caminhos dos recursos usam caminhos relativos.

Observação: o instalador do XAMPP que estava dentro da pasta original não foi incluído, pois não faz parte do site e aumentaria o ZIP em mais de 150 MB.
